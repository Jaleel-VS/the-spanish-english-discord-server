Rai is the bot the moderators rely on. It logs joins, leaves, edits and deletions, screens new accounts, handles mutes and bans with a duration, and keeps the questions queue so a hard question doesn't get swept away in the channel.

This page is a placeholder. A full write-up of what the bot does, and which commands members (not just moderators) can use, is coming.

## Commands people use most

| Command | What it does |
| --- | --- |
| `;u` | Your profile: activity and which languages you've been writing in |
| `;ul` | Just your language percentages from the last 30 days |
| `;lb` | The server leaderboard for the last month |
| `;chlb` | The leaderboard for the current channel |
| `;pencil` | Adds a pencil to your name to say you'd like to be corrected; `;eraser` removes it |

Rai's commands start with a semicolon.
