Hablemos es el bot escrito para este servidor. Guarda tus notas de vocabulario, lleva la Liga de Idiomas y tiene algunos juegos para practicar entre conversaciones.

Esta página es provisional. Pronto habrá una descripción completa de lo que hace el bot y de cómo usar cada función.

## Los comandos más usados

| Comando | Qué hace |
| --- | --- |
| `/help` | Ayuda interactiva, por categorías |
| `/vocab add` | Guarda una palabra o frase con su traducción; tus notas son privadas |
| `/vocab list` | Muestra tus notas |
| `/vocab search` | Busca en tus notas por palabra o traducción |
| `/league join` | Únete a la Liga de Idiomas, la clasificación semanal |
| `/league view` | Muestra la clasificación en español, en inglés o combinada |
| `/deletemydata` | Borra todo lo que el bot guarda sobre ti |

Los comandos de barra (`/`) muestran sus opciones mientras escribes. Algunos comandos antiguos usan el prefijo `$`, por ejemplo `$ping`.
