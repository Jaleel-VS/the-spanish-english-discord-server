Hablemos is the bot written for this server. It keeps vocabulary notes for you, runs the Language League, and has a few games for practising between conversations.

This page is a placeholder. A full write-up of what the bot does and how to use each feature is coming.

## Commands people use most

| Command | What it does |
| --- | --- |
| `/help` | Interactive help, by category |
| `/vocab add` | Save a word or phrase with its translation; your notes are private |
| `/vocab list` | See your notes |
| `/vocab search` | Search your notes by word or translation |
| `/league join` | Join the Language League, the weekly leaderboard |
| `/league view` | See the Spanish, English or combined rankings |
| `/deletemydata` | Delete everything the bot stores about you |

Slash commands (`/`) show their options as you type. A few older commands use the `$` prefix instead, for example `$ping`.
